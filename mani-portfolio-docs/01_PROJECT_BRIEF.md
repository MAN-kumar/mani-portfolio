# 01 — PROJECT BRIEF

## Project
**Mani — Interactive Personal Portfolio & Digital Identity**

## Vision
Build the portfolio like a product, not a generic resume website.

The portfolio should communicate:
- Who Mani is
- What Mani builds
- What Mani has researched
- What Mani can do
- Why the work matters
- How visitors can connect

## Core Principle
> **CONTENT IS DATA. UI IS A SYSTEM.**

The same structured content should power the homepage, project cards, project details, search, filters, related content, research, skills, and future CMS/API.

## Visitor Flow
**See → Understand → Explore → Discover → Deep Dive → Trust → Connect**

## Owner Flow
**Update Data → Content System → UI Updates → Entire Portfolio**

## Core Sections
- Home
- About
- Projects
- Project Case Studies
- Research Lab
- Skills
- Journey
- Resume
- Contact

## Long-Term Vision
Evolve the portfolio into a personal professional/knowledge platform with:
- Django REST API
- PostgreSQL
- Admin/CMS
- GitHub integration
- Research dashboard
- Analytics
- AI assistant

## Initial Technology
- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Three.js / React Three Fiber
- Django
- Django REST Framework
- PostgreSQL

## Success Criteria
The portfolio should be:
- Professional
- Interactive
- Fast
- Responsive
- Easy to maintain
- Recruiter-friendly
- Research-friendly
- Technically impressive
- Ready for future CMS/API migration
