# 03 — DESIGN SYSTEM

## Visual Direction
Dark-first, technical, premium, minimal and interactive.

## Color System
Use:
- Near-black/deep charcoal background
- Dark surfaces
- Subtle borders
- Near-white primary text
- Muted secondary text
- One signature accent

Avoid excessive:
- Gradients
- Glassmorphism
- Shadows
- Neon colors
- Visual noise

## Typography
Possible primary fonts:
- Inter
- Geist
- Manrope
- Satoshi
- DM Sans

Monospace may be used for technical accents.

## Type Scale
- Display: 64–96px
- H1: 48–72px
- H2: 36–48px
- H3: 24–32px
- Large body: 20px
- Body: 16px
- Small: 14px
- Caption: 12px

## Spacing
Use a 4px base:
4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 80 / 96 / 128 / 160

## Layout
- Max width: approximately 1200–1400px
- Desktop: 12 columns
- Tablet: 8 columns
- Mobile: 4 columns

## Section Pattern
Each section can use:
1. Number/eyebrow
2. Heading
3. Description
4. Content

## Buttons
Variants:
- Primary
- Secondary
- Ghost/tertiary

States:
- Default
- Hover
- Active
- Focus
- Disabled
- Loading

## Project Cards
Should include:
- Number
- Image
- Category
- Title
- Description
- Technology tags
- Status/year
- CTA

## Project Detail Story
- Hero
- Overview
- Problem
- Objective
- Approach
- Technology
- Architecture
- Implementation
- Experiments
- Results
- Challenges
- Learnings
- Future work
- Links
- Related projects

## 3D
3D is supporting content, not the entire experience.
- Lazy load
- Fallback
- Mobile-friendly
- Reduced-motion support

## Motion
- Micro: 150–250ms
- Component: 250–450ms
- Section: 400–800ms
- Use transform/opacity/scale/translate
- Avoid excessive motion

- 3D components
